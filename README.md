# Event Service

## RU

Сервис Nuntius для анализа событий. Получает статьи из News Service, анализирует содержание статей, сравнивает их между собой и определяет какие статьи относятся к одному событию.

## EN

Nuntius event analysis service. Receives articles from News Service, analyzes their content, compares articles with each other, and determines which articles relate to the same event.
